# Секреты и demo

Ключ DeepSeek — серверная переменная. Для одного владельца ввод ключа в браузер ничего не добавляет и повышает риск утечки.

Токен Threads шифруется Fernet ключом вне базы.

Demo — отдельные классы, а не «тихий» вызов боевого API. Ответ помечается `is_demo_publication`, permalink пустой, внешний id начинается с `demo:`. Переключить режим из UI нельзя.
