# Безопасность

Установка рассчитана на одного владельца. Пароль задаётся в `ACWA_AUTH_TOKEN` и обязателен: без него API и worker не запускаются, а интерфейс показывает только форму входа. Пароль передаётся как `Authorization: Bearer` и хранится в браузере только до закрытия вкладки. Это общий секрет установки, не учётные записи нескольких людей. Compose слушает только localhost.

Токен Threads шифруется Fernet. Ключ — `ACWA_TOKEN_ENCRYPTION_KEY`, он не хранится в базе. Потеря ключа делает сохранённые токены нечитаемыми, их нужно получить заново. Ключ из `.env.example` годится только для demo. Live-режим с ним не стартует.

Ключ DeepSeek остаётся в окружении сервера. Ответы API отдают лишь факт настройки, модель и базовый URL. Сохранённый токен Threads наружу не отдаётся, в том числе частично.

Запрещено:

- писать секреты в git, URL фронтенда и логи;
- возвращать ciphertext, Authorization и access token в JSON;
- подставлять ключи в клиентский bundle.

OAuth `state` одноразовый и живёт 15 минут. Секрет приложения Threads уходит только в серверный обмен кода.

Логи JSON содержат id кампании, поста и задания. Форматер вырезает bearer, access_token, client_secret и api key. Тексты ошибок внешних API проходят через ту же очистку.

Отключение аккаунта стирает ciphertext и ставит активные кампании на паузу. Отзыв доступа на стороне Threads этим запросом не выполняется: в использованной документации отдельного revoke для этого сценария нет, пользователь отключает приложение в настройках Threads.

Промпт говорит модели вернуть только JSON с полем `text`. Настройки пользователя не меняют системные правила приложения.
