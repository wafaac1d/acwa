# Соглашения

Код и имена API на английском, интерфейс на русском. Идентификаторы в snake_case на backend и camelCase не используются в JSON: контракт повторяет поля Python.

Время в API — ISO-8601 с часовым поясом. Отдельно передаются IANA-зона кампании и уже посчитанное локальное время слота.

Ошибки только через `ApiError` и формат `error.code`, `error.message`, `error.fields`. Пользователю не показываются traceback и сырой ответ провайдера, если в нём может быть секрет.

Транзакция запроса коммитится в зависимости FastAPI. Перед внешним HTTP worker коммитит состояние, чтобы не держать соединение с базой во время сети. Повторный коммит внутри сервиса допустим, когда нужно сохранить `publish_dispatched_at` до вызова Threads.

Новая миграция описывает изменение схемы. Модели SQLAlchemy и миграция должны совпадать.

Документация обновляется в том же изменении, если меняются режим, расписание, статусы или внешний контракт.
