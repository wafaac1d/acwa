# Тестирование

Юнит-тесты не зависят от текущего времени: расписание и worker получают `FrozenClock`.

Пароль приложения в интеграционных тестах — `integration-test-password`. Ответ без пароля и с неверным паролем должен быть 401 и не содержать секрет.

- проверка кампании и текста, включая лимит 500 и запреты;
- сборка промпта и версия шаблона;
- ближайший слот, пропуск несуществующего DST-времени, выбор раннего смещения при перекрытии;
- пропущенные слоты и пауза;
- ручное одобрение до публикации;
- повтор публикации без нового вызова генератора;
- `FOR UPDATE SKIP LOCKED` и восстановление зависшей публикации в `UNKNOWN`;
- обработка задания новым процессом;
- rate limit и истёкшая авторизация Threads;
- постоянная ошибка генерации;
- таймаут публикации без второго вызова;
- отсутствие ключа и токена в ответах API.

Интеграционные тесты поднимают PostgreSQL 16. Внешние HTTP в них не используются: demo-клиенты и `httpx.MockTransport`.

```bash
cd backend
uv run pytest
uv run ruff check src tests
uv run mypy src
cd ../frontend
npm test
npm run build
```

Playwright-сценарий `frontend/e2e/demo.spec.ts` проходит UI в demo, когда стек уже запущен на `ACWA_E2E_BASE_URL`.
