# Для агентов

Репозиторий — модульный монолит Account Warm-up. Backend и worker — один Python-пакет `backend/src/acwa`. Интерфейс — отдельное приложение `frontend`.

Перед изменением поведения прочитай `docs/architecture.md`, `docs/product.md` и соответствующее правило в `.cursor/rules`.

- Не вызывай DeepSeek и Threads из браузера.
- Пароль приложения — `ACWA_AUTH_TOKEN`. Не запускай API без него и не возвращай пароль клиенту.
- Не логируй и не возвращай токены, ключи и ciphertext.
- Не выдумывай поля внешних API. Официальные ограничения описаны в `docs/configuration.md`.
- Расписание и задания живут в PostgreSQL. Не заменяй worker на `BackgroundTasks` или память процесса.
- Повтор публикации не создаёт новый текст.
- После простоя не публикуй пачку пропущенных слотов.
- Demo-режим не должен выглядеть как настоящая публикация в Threads.
- Если меняется поведение, обнови документацию и OpenAPI-типы командой из README.
- Не включай реальную публикацию в тестах, миграциях и при старте приложения.
